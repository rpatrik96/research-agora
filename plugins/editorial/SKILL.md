# Editorial Skills

Diagnostic editorial intelligence for writing across contexts — papers, blogs, books, grants. Analyzes, diagnoses, and translates rather than generating from scratch.

## Available Commands

| Command | Description |
|---------|-------------|
| `/argument-autopsy` | Diagnose logical structure and argument flow |
| `/writing-diagnosis` | Identify named writing failure patterns with educational feedback |
| `/writing-verify` | Quantitative writing quality verification with A-F grade and dimension scores |

## Installation

```bash
/plugin install editorial@research-agora
```
