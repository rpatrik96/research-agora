# Academic Skills

Academic paper writing skills for ML conferences (NeurIPS, ICML, ICLR, AAAI).

## Available Commands

| Command | Description |
|---------|-------------|
| `/brainstorm` | Checkpoint-gated interactive brainstorming for research decisions |
| `/paper-introduction` | Write or improve introduction sections |
| `/paper-abstract` | Write or improve abstracts |
| `/literature-synthesizer` | Write related work and discover relevant literature |
| `/paper-discussion` | Write discussion and limitations sections |
| `/paper-experiments` | Write experimental details with GitHub integration |
| `/paper-review` | Generate critical reviews simulating reviewers |
| `/review-triage` | Triage reviewer comments and plan the revision |
| `/paper-references` | Fact-check references and citations |
| `/paper-verify-experiments` | Verify claims against source code |
| `/paper-poster` | Create conference posters |
| `/paper-slides` | Create presentation slides |
| `/literature-synthesizer` | Discover and synthesize relevant literature |
| `/experiment-tracker` | Sync experiment results to paper drafts |
| `/benchmark-scout` | Identify benchmarks and generate experiment plans |
| `/onboard` | Personalized onboarding: interview → tier classification → CLAUDE.md generation |
| `/review-prompt` | Critique prompts using RIOT framework with named failure modes |
| `/choose-skill` | Natural-language task → skill recommendation with confidence scores |
| `/five-minute-win` | Auto-detect project files and suggest fastest demo |
| `/whats-new` | Returning-user changelog filtered by research impact |

## Installation

```bash
/plugin install academic@research-agora
```
